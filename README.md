# 🗺️ Pepcoding Master DSA Roadmap

An interactive, 15-phase Beginner-to-Advanced DSA Master Architecture tracking **777 total Pepcoding videos** (554 Level 1 + 223 Level 2) with **550 curated LeetCode practice questions** sourced directly from Kunal Kushwaha's assignments.

## 🚀 Features

- **Strict Learning Order**: Big-O, 1D & 2D arrays, recursion, sorting, monotonic stacks, and BST invariants are taught in prerequisite sequence.
- **550 Curated LeetCode Problems**: Organized topic-by-topic with Easy, Medium, and Hard tiers and direct links.
- **Interactive Progress Tracking**: Check off topics and individual LeetCode problems with progress persisted in `localStorage`.
- **Export & Import Backup**: Download your full progress state as `dsa-master-roadmap-v3.json` and sync across devices.
- **Hosted on GitHub Pages**: Zero backend needed, 100% static client-side web application.
